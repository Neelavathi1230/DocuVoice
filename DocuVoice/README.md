# DocuVoice – Document-to-Speech & Text Analysis System
Upload a TXT, MD, DOCX or PDF (or paste text); get summaries, keywords, key information (dates, amounts, names, emails, phones, links), outline, document type and readability, and listen to the document or its summary with sentence highlighting.

## Run
```bash
pip install -r requirements.txt
cd backend && uvicorn main:app --reload      # http://127.0.0.1:8000
```

## How it works
- **Extraction** (`backend/extract.py`): TXT/MD direct; DOCX parsed from its XML (no extra library; Word headings become outline); PDF via `pypdf` (scanned/image PDFs need OCR, not included).
- **Analysis** (`backend/nlp.py`, local, replaceable): extractive summaries (3 lengths), keyword/bigram frequency, regex key-information extraction, heading detection, rule-based document typing, Flesch readability.
- **Read aloud** (real, in the browser): Web Speech API `speechSynthesis`, read sentence by sentence with play/pause/stop, speed and voice choice; click a sentence to start from it. Available voices depend on your browser/OS.

## API
`POST /api/auth/{register,login,logout}` · `POST /api/documents` (file or text) · `GET /api/documents` · `GET|DELETE /api/documents/{id}`

## Limits
Speech is generated by the browser, so no audio file download. Summaries are extractive (sentences copied, not rewritten). Document typing and entity detection are heuristics. Future work: server-side TTS to MP3 (e.g. pyttsx3/gTTS), OCR, transformer summaries, multilingual support.
